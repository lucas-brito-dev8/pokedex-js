# Pokédex

A simple Pokédex project made to practice JavaScript concepts like:

- async/await
- fetch API
- DOM manipulation
- error handling
- CSS states/classes
- Express server setup

Users can search for a Pokémon by name and see information such as:

- image
- type
- height
- weight

This project was built mainly for learning and improving frontend/backend fundamentals with JavaScript.

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express
